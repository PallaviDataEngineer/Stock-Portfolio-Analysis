# Stock Portfolio Performance & Analysis Dashboard

## Project Overview
An interactive Stock Portfolio Performance & Analysis Dashboard developed using Microsoft Power BI to analyse investment performance, portfolio allocation, sector-wise investments and individual stock contributions.

## Dashboard Preview

![Stock Portfolio Dashboard](Stock%20Portfolio%20Dashboard%20Image.png)

## Dashboard Features
- Total Investment
- Current Portfolio Value
- Total Profit/Loss
- Portfolio Return %
- Portfolio Allocation by Asset Type
- Sector-wise Investment Analysis
- Top 5 Holdings by Market Value
- Top 10 Holdings – Profit/Loss Contribution
- Interactive filters for Asset Type, Sector and Company
- Detailed Portfolio Holdings Summary

## Tools & Technologies
- Microsoft Power BI
- DAX
- Power Query
- Data Modelling
- Data Visualization

## Key Learnings
- Data cleaning and transformation
- Creating DAX measures
- Building interactive dashboards
- Applying conditional formatting
- Analysing portfolio performance and investment trends
